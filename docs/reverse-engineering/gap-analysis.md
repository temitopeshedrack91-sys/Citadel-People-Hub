# Citadel / NotchHR documented-scope gap analysis

**Comparison basis:** Citadel source audit and public NotchHR product pages. NotchHR's private application was inaccessible and no demo account was available. “NotchHR finding” therefore means a documented vendor claim, not verified behavior. See [NotchHR product analysis](notchhr-product-analysis.md).

| Feature | Citadel existing implementation | NotchHR finding | Gap / risk | Classification | Action |

## Implementation completed in this pass

This pass prioritizes the verified high-risk Laravel access defects: task and project record scoping, safe relationship assignment, and leave-balance endpoint scoping. These do not depend on undocumented NotchHR behavior. Larger policy-dependent calculation engines remain specified but are not guessed into the production model.
